🎯 Lộ trình học AI/ML Security 2026

Linda (CEO) | 27/02/2026

Từ số 0 đến chuyên gia bảo mật AI - Lộ trình 12 tháng dành cho người mới bắt đầu.

📋 Tổng quan:
Thời gian đọc: 15 phút | Trình độ: Beginner → Advanced | Thời lượng: 12 tháng

📋 Giới thiệu

AI/ML đang thay đổi mọi ngành công nghiệp - nhưng đi kèm với cơ hội là những lỗ hổng bảo mật hoàn toàn mới. Hệ thống AI/ML có các attack vectors (hướng tấn công) mà các security researcher truyền thống có thể chưa quen thuộc.

Lộ trình này dành cho:

  • Web security researcher muốn chuyển sang AI/ML security
  • Developer tò mò về lỗ hổng AI
  • Người mới bắt đầu từ con số 0

🗺️ Phase 1: Xây dựng nền tảng (Tháng 1-2)

Trước khi học AI security, bạn cần nền tảng vững về khoa học máy tính và web security.

1.1 Khoa học máy tính cơ bản ⭐⭐⭐

Chủ đề Tài liệu Thời gian Ưu tiên
Mạng máy tính Network+ (Professor Messer), Wireshark labs 2 tuần 🔴 Cao
Linux/Unix OverTheWire Bandit, Linux Journey 2 tuần 🔴 Cao
Python cho Security "Black Hat Python", HackTheBox 3 tuần 🔴 Cao
Git & Version Control GitHub Skills, Git Immersion 1 tuần 🟡 Trung bình
💡 Thực hành:
  • Hoàn thành OverTheWire Bandit (Levels 1-34) - học Linux commands qua game
  • Viết 3 tools Python: port scanner, directory brute-forcer, HTTP fuzzer
  • Viết write-up (báo cáo kỹ thuật) cho blog cá nhân

1.2 Web Security cơ bản ⭐⭐⭐⭐

Chủ đề Tài liệu Thời gian Ưu tiên
OWASP Top 10 OWASP.org, PortSwigger Academy 3 tuần 🔴 Cao
Burp Suite PortSwigger Academy 2 tuần 🔴 Cao
SQL Injection PortSwigger SQLi labs 1 tuần 🔴 Cao
XSS PortSwigger XSS labs 1 tuần 🔴 Cao
💡 Thực hành:
  • Hoàn thành PortSwigger Web Security Academy (mức Apprentice)
  • Tìm 5 bugs hợp lệ trên HackerOne (bất kỳ chương trình nào)

🤖 Phase 2: Chuyên sâu AI/ML Security (Tháng 3-6)

Khi đã có nền tảng, giờ là lúc chuyên sâu vào AI/ML security.

2.1 Machine Learning cơ bản ⭐⭐⭐⭐

Chủ đề Tài liệu Thời gian Ưu tiên
ML Basics Coursera ML (Andrew Ng), Fast.ai 4 tuần 🔴 Cao
Deep Learning "Deep Learning" (Goodfellow), PyTorch tutorials 4 tuần 🔴 Cao
Model Architectures Transformers, CNNs, RNNs, GANs 3 tuần 🔴 Cao
ML Frameworks PyTorch, TensorFlow, HuggingFace 3 tuần 🔴 Cao
💡 Thực hành:
  • Xây dựng và train 3 neural networks: image classifier (CNN), text generator (RNN/Transformer), recommender system
  • Hiểu các định dạng model file: GGUF, ONNX, SafeTensors, Pickle
  • Viết blog: "AI Models hoạt động thế nào (dành cho Security Researchers)"

2.2 AI/ML Attack Vectors ⭐⭐⭐⭐⭐

Đây là phần quan trọng nhất - học cách tấn công hệ thống AI/ML.

Chủ đề Tài liệu Thời gian Ưu tiên
Adversarial ML "Adversarial Machine Learning" (Huang et al.), CleverHans 3 tuần 🔴 Cao
Model Inversion Research papers về model extraction attacks 2 tuần 🔴 Cao
Data Poisoning Supply chain attacks trên ML pipelines 2 tuần 🔴 Cao
Prompt Injection LLM security, promptfoo, Garfinkel et al. 3 tuần 🔴 Cao
Model File Exploitation Lỗ hổng parsing GGUF, TensorRT, ONNX 4 tuần 🔴 Cao
💡 Thực hành:
  • Reproduce 3 adversarial ML attacks từ research papers
  • Tạo proof-of-concept cho 1 lỗ hổng model file format
  • Submit 1 bug report lên chương trình AI/ML bounty

2.3 AI Security Tools ⭐⭐⭐

Tool Mục đích Ưu tiên

promptfoo Framework test security cho LLM 🔴 Cao
CleverHans Thư viện adversarial examples 🟡 Trung bình
ART Đánh giá security cho ML models 🟡 Trung bình

🔬 Phase 3: Nghiên cứu nâng cao (Tháng 7-12)

Giai đoạn cuối - đẩy giới hạn và khám phá lỗ hổng mới.

3.1 Advanced Exploitation ⭐⭐⭐⭐⭐

  • Deserialization Attacks: Pickle, Joblib, YAML, Pickle RCE
  • SSTI trong ML: Jinja2 trong model metadata, template injection
  • Memory Corruption: Buffer overflows trong model parsers (C/C++)
  • Supply Chain Attacks: Dependency confusion, typosquatting ML packages
💡 Mục tiêu:
  • Khám phá 1 lỗ hổng critical (CVSS 9.0+)
  • Submit lên bounty program public (Huntr, HackerOne)
  • Thuyết trình tại meetup/conference về AI security

3.2 Research & Publication ⭐⭐⭐

  • Nghiên cứu gốc: Attack vector mới cho AI
  • Blog Posts: 1 bài/tháng về AI security
  • Conference Talks: Submit lên DEF CON AI Village, Black Hat
  • GitHub Projects: Open-source AI security tools

🚀 Bắt đầu NGAY HÔM NAY

Đừng chờ đợi - bắt đầu học ngay! Checklist cho ngày đầu tiên:

  1. Đăng ký PortSwigger Web Security Academy (miễn phí) - Bắt đầu với track "Server-side vulnerabilities"
  2. Cài OverTheWire Bandit - Hoàn thành levels 1-5 hôm nay
  3. Setup môi trường học: Python 3.11+, VS Code, tạo GitHub account
  4. Tham gia community: Follow researchers AI security trên Twitter/X, join Discord servers
  5. Bắt đầu learning journal: Ghi chép những gì học được mỗi ngày
🔥 Lời kết:
AI/ML security là lĩnh vực đang phát triển nhanh với cơ hội lớn. Chìa khóa thành công:

✅ Kiên trì - Học mỗi ngày
✅ Thực hành - Lý thuyết phải đi đôi với thực tế
✅ Cộng đồng - Kết nối với researchers khác
✅ Tò mò - Luôn tự hỏi "what if?" và "làm sao để phá?"
